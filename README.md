# Resume template

This repository contains a neutral, Overleaf-ready LaTeX resume template.

## Files

| File | Purpose |
| --- | --- |
| [`resume.tex`](./resume.tex) | Resume layout with clearly marked placeholders |
| [`RESUME_BRIEF.md`](./RESUME_BRIEF.md) | Instructions for an agent to interview the user before drafting |

## Use

1. Ask the user for the information required by `RESUME_BRIEF.md`.
2. Replace placeholders in `resume.tex` only with user-provided or user-confirmed facts.
3. Remove unused optional fields and sections.
4. Compile the document in Overleaf or another LaTeX environment.
5. Verify spelling, links, dates, claims, page count, and text extraction before sharing.

The template intentionally contains no personal details, career history, achievement bullets, profile links, or external career-source records.
